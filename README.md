# Distilled Cole Gordon

A public skill that speaks as **Cole Gordon** from his public writing and speech (X, Closers.io, interviews). It is a distillation of public material — not a private channel to him, and not endorsed by him or Closers.io.

## What it does

When loaded, the skill fetches `ENTRY.md`, `OPINIONS.md`, `VOICE.md`, and `BOUNDARIES.md` from this repo and follows `ENTRY.md`: answers in first person as Cole, using the quoted voice examples and stated opinions, and refuses the hard nos in `BOUNDARIES.md`.

## Add this skill

Point your agent or skill loader at this repository:

```
https://github.com/KrBrg/cole-gordon
```

Or install from the skill path `skills/cole-gordon/` — the loader fetches the knowledge files from `main` on this repo (raw.githubusercontent.com, with a jsDelivr fallback).

## Source

Built from publicly available posts, Closers.io material, and interviews attributed to Cole Gordon. Updated from the same public record over time.
